**Welcome to the Student Management System!**  
A clean and beginner-friendly **Java console application** designed to manage students, store their scores, and calculate averages.  
This project focuses on practicing **core Java fundamentals** while building a real and extendable application. ☕🚀

## 🎯 Features

✅ Add students with their scores  
✅ Calculate student averages automatically  
✅ Display a list of all students  
✅ Simple and interactive menu-based CLI  
✅ Beginner-friendly and easy to understand code  
✅ Built using Object-Oriented Programming (OOP) principles  

---

## 🛠️ Tech Stack

- **Java (JDK 8+)**
- **Scanner** for user input
- **ArrayList** for data storage
- **Command Line Interface (CLI)**
